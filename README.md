### What I work on

- **Cloud & Serverless Architecture**: Lifetime $0-cost designs with AWS CDK v2, EventBridge, Lambda Function URLs, Docker, and Fly.io.
- **REST APIs, Webhooks & Integrations**: Node.js, Rust/Axum, API reverse engineering, payment gateways (Culqi, MercadoPago), and resilient caching/fallbacks.
- **Native Android & Systems**: Jetpack Compose, Android `CallScreeningService`, embedded Go (`whatsmeow`) via `gomobile`/JNI, and multi-module architectures.
- **Offline-First & Multimedia**: PWA and hybrid apps with Capacitor 8, background sync (IndexedDB), on-device OCR, and Media3 ExoPlayer with Chromecast/DLNA streaming.
- **Applied AI & GenAI**: Lightweight RAG pipelines (LlamaIndex, NVIDIA NIM) and computer vision (OpenCV, YOLO).
